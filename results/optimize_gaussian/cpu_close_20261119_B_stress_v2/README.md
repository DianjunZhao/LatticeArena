# Package B fit-state stress diagnostic

Generated by `python -m tasks.optimize_gaussian.estimator_regression_stress`.
The full dataset-level rows, intervals, bootstrap summaries and source hashes are in
`stress_regression.json`. This is a synthetic CPU stress test; it does not use production gauge data.

## Frozen design

- 200 independent datasets per scenario cell, 200 paired bootstrap draws per dataset; 80 configurations, temporal extent 9,
  one channel, true mass 0.5, true amplitude 1, and 3% multiplicative noise.
- Noise is AR(1) in time with $\rho_t=0.5$ and in configuration order with $\rho_{cfg}=0,0.5,0.8$.
- Block lengths are 2, 5 and 10. Training and validation use ordered first/last segments with a two-block embargo; no random
  block interleaving is used, so adjacent correlated configurations are not split across both samples.
- The wrong-reference scan shifts the assumed mass by 0, 0.02 or 0.05. For each dataset, intervals are checked against the
  known true $q(t)$ profile. Separately, the report checks whether the bootstrap intervals contain $q(t)=1$, the reference-shape
  null. These answer different questions: a confidence interval can cover a shifted true $q(t)$ while rejecting the reference.
- Three branches are compared: training amplitude held fixed (conditional), training amplitude resampled jointly with each
  validation replica and reference-mass draw, and validation amplitude refit with the same point/replica rule.

## Results

Under the correct mass and $\rho_{cfg}=0$, the all-score-window coverage at block length 2 was 0.975 / 0.925 / 0.900 for
conditional train-frozen / joint-amplitude-propagated / validation-refit. At block length 10 it was 0.935 / 0.715 / 0.595.
For $\rho_{cfg}=0.8$ and block length 10 it was 0.885 / 0.650 / 0.555. Each fraction uses 200 independent datasets and has
an exact 95% Clopper–Pearson interval in the JSON. Larger block sizes leave fewer blocks in this fixed 80-configuration design,
so the scan is a finite-sample sensitivity study, not a rule that one block length is universally best.

For the wrong-reference scan, a mass offset of 0.02 gives mean RMS true-shape departure $\\mathrm{RMS}(q_{true}-1)=0.0334$;
at offset 0.05 it is 0.0944. At both offsets, none of the 200 datasets had all four bootstrap intervals include $q=1$, even
though the intervals covered the shifted true $q(t)$ profile in 97% of training-frozen cases. This illustrates why statistical
interval coverage and physical reference validity must remain separate gates.

Jointly resampling the training amplitude with the reference-mass draws sometimes **narrows** rather than widens the $q$ interval
(for $\rho_{cfg}=0$, block 2, mean width 0.0336 conditional versus 0.0252 joint). Amplitude and mass shifts compensate in the
normalization; propagating one marginal error independently would miss this covariance. The direction and size are specific to
this synthetic estimator and require real-data confirmation.

## Limits

This test validates the point/replica bookkeeping under the declared toy model, not unconditional physical coverage, a realistic
reference fit, or a learned-smear advantage. It has one channel, one mass, fixed parametric mass draws and synthetic noise. The
configuration block scan is based on 80 samples, so its exact MC interval quantifies simulation repetition but not physics
systematics. Production W training and the blind GPU comparison remain `NOT_RUN`.
