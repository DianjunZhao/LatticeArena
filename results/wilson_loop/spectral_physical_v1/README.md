# 两态静态源反例（P3）

生成：`python -m tasks.wilson_loop.spectral_physical`；数值：`spectral_physical.json`；
图：`spectral_physical.png`。

**负结果（gate 不足，不是认证）**：下表的 spread gate 全部通过，而短窗值系统性偏离 $E_0$；
`window_paired_z` 只是诊断量，未进入 gate。任何“gate PASS”都不能读作 E0 已认证。

## 构造

零温形式 $W(T)=c_0e^{-E_0T}+c_1e^{-E_1T}$，$E_0=0.5$、$E_1=1.2$、$c_0=1$，
80 组态/16 blocks、0.5% 噪声；窗口与正式分析一致（`[4,5,6]`、`[4,5,6,7]`、`[5,6,7,8]`）。

## 结果（扫描 $c_1$）

| $c_1$ | 短窗口 bias | bias/SE | spread/V | max\|paired z\| | spread gate |
| ---: | ---: | ---: | ---: | ---: | --- |
| 0 | 0.0002 | 0.8 | 0.0000 | 0.03 | 通过 |
| 0.02 | 0.0001 | 0.5 | 0.0007 | 2.28 | 通过 |
| 0.05 | 0.0009 | **3.1** | 0.0004 | 1.02 | 通过 |
| 0.1 | 0.0018 | **5.6** | 0.0014 | 3.01 | 通过 |
| 0.2 | 0.0033 | **13.1** | 0.0019 | **5.43** | 通过 |
| 0.3 | 0.0053 | **19.7** | 0.0031 | **8.77** | 通过 |
| 0.5 | 0.0090 | **32.5** | 0.0058 | **16.65** | 通过 |

读数：

- **spread gate 完全看不见共同偏差**：所有 $c_1$ 都通过（spread/V ≤ 0.006 ≪ 5%），
  而 bias 从 0.8σ 涨到 32.5σ；
- 配对差口径的 `window_paired_z` 在 $c_1=0.1$ 时约 3.0，$c_1\ge0.2$ 时 5.4/8.8/16.7；
  它仍只是诊断量，不进入 gate——它比 spread 敏感，但也不是“E0 准确”的证明；
- 结论：短窗口拟合可以在“窗口一致”的同时系统性偏离 $E_0$；gate PASS 不能升级为 E0 准确度。

## 有限 $N_t$ 的谱

静态源 sector 的 Wilson 圈：

$$
W(R,T)=\sum_n c_n(R)\left(e^{-E_n(R)T}+e^{-E_n(R)(N_t-T)}\right)
$$

（周期时间、零动量）。零温近似只保留 $e^{-E_nT}$；回绕项在 $T=N_t/2$ 时与正向项同量级，
因此**不能**假设它总是 $10^{-4}$–$10^{-6}$。但“等幅回绕”只是 $c_n$ 相等的一个特例，
不能反过来断言 Wilson 圈一定含该项——本反例用的是零温形式，回绕的影响见
[`doc/wilson_spectral_quality.md`](../../../doc/wilson_spectral_quality.md)。

## 限制

- 未比较不同协方差估计（条件数）与预声明拟合的敏感性；
- 未做可识别/不可识别区间的完整扫描（只扫了 7 个 $c_1$）。
